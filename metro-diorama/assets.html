Diorama Asset Workshop

Every sprite in the Metro diorama is generated from code in src/assets/ using the palette in src/palette.js. Download any sprite, repaint it in Aseprite or Photoshop at the same size, save it to overrides/, and list it in config.js → overrides (e.g. { tower: 'overrides/tower.png' }). The scene uses your PNG instead.
